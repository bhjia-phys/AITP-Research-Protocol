# 自然使用 session 记录模板

非 gate、非 spec、非冻结材料。每次普通自然使用 session 结束后,把本模板复制为
`feedback/YYYY-MM-DD-<topic-slug>-natural-use.md`,填 4–6 行即可。只记录可观察
事实;不写推论,不声称 AITP 优于 plain files,也不更改任何 freeze disposition。

- **Topic / 日期**:
- **恢复耗时**:从会话开始到拿到可靠当前结论,大致花了多久(工具调用数或分钟均可)?
- **handoff**:`enter` 的 handoff 是否已过时?根因是没写新 closeout,还是别的?
- **漏记**:有没有真正 durable 的事件当时没进 ledger,事后才补?
- **写入成本**:记录动作占了多少时间/工具调用?哪一步最重?
- **remote evidence**:是否重复搬运了远端 provenance?
- **检索**:`rg` + `show` 有没有答不了的问题?
- **自然需求**:本轮是否出现 roster B / D / E / Followup 6 或其他候选的真实需求?(无则写"无")
