# docs/archive/ — frozen historical records

Files in this directory are **frozen and not maintained**. They were moved
here on 2026-08-12 from `docs/` as part of the governance slim-down. The
active authoritative surface is now only:

- `README.md` — usage and current capability.
- `docs/design.md` — current stable runtime/schema contracts.
- `docs/roadmap.md` — stage status, budgets, and next-decision triggers.
- `docs/m1b-spec.md` §0.1 — the frozen A–H candidate roster and dispositions.
- `plugins/aitp-research-protocol/skills/using-aitp/SKILL.md` — the agent's operating protocol.
- `docs/hakimi/` — the cross-repo integration contract.

Rules for archived files:

- They take no part in any same-change sync discipline.
- Their content is historical evidence of decisions and gates; it is **not
  edited** to reflect new state.
- Internal relative links were not rewritten: interpret them from the file's
  original `docs/` location. Links from active docs were updated to point
  here.
- Deferred capability contracts archived here are **historical candidates,
  not default designs**: if a need reappears, re-derive it from fresh
  natural-use evidence instead of resurrecting the old contract.
