# Find and retain a domain method

Use the topic's main note and relevant links to identify a method already used
there. AITP's shareable methods are grouped by domain under
`aitp-research/methods/<domain>/`. Each domain's README indexes its methods, its
conventions and checks, and the standard sources for those methods. Indexes exist for
[GW, RPA and LibRPA](../methods/librpa/README.md), whose first method is
[developing LibRPA](../methods/librpa/developing-librpa/SKILL.md), and for
[quantum chaos](../methods/quantum-chaos/README.md), which so far holds conventions and
sources only. Read an index or method only when its task matches the present work; do
not load the library at topic entry. Domain folders are ordinary organization, not
separate protocols.

Keep general, shareable procedures in this library when editing AITP is within
the task's scope. Keep unpublished evidence, account settings and local paths in
the topic or its established shared family location. An unreviewed method can
remain in `topic/skills/<method>/SKILL.md` until its reusable part is ready for
inclusion. List it in the topic family's README, which is the workspace side of the
domain's methods. Existing local Skills remain useful; no migration is required.

Use [aitp-distill](../../aitp-distill/SKILL.md) to extract or revise a procedure
from the main note and its evidence. Add an ordinary relevant link for discovery;
there is no registry or knowledge-card layer. The domain indexes linked from
`aitp-research` provide portable discovery. Host catalogs can differ: Codex can also
expose a nested `SKILL.md` directly, while Hakimi loads the containing research Skill as
one bundle. AITP has seven core Skills, but a host may list more selectable Skills, such
as a directly exposed nested method. A directly selected method still runs inside
[memory's research cycle](../../aitp-memory/SKILL.md#the-research-cycle) for
research-topic work. Do not edit an installed plugin cache as its durable home.

Generalizing a procedure does not authorize publishing its motivating research
note, data or examples. Preserve any review boundary already specified by the
researcher. Prepare those materials outside the outgoing public tree until their
publication is authorized; a generic method should be usable without them.
