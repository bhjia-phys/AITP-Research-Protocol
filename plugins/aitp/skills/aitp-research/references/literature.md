# Literature that changes the research judgment

Search when a needed concept or theorem is not established, a convention-sensitive
claim is imported, a proposed method may already exist, contradictory sources
matter, or the user requests related/current literature. Do not make web search
a ritual before every algebraic step. Reuse an inspected source when it answers
the same question and its freshness is adequate.

Write down the question the source must answer: for example, the hypotheses of
a theorem, the precise meaning of an interaction tensor, or the existence of a
particular junction construction. Search by that question and its mathematical
objects. Use arXiv, journal/publisher pages and available scholarly indexes to
locate primary works. Reviews can orient; read the original relevant passage
before attributing a technical result.

Keep author/title/year and a DOI or arXiv locator, plus the equation, section or
page that supports the claim. Distinguish the paper's result from the inference
made for this topic. Note a convention translation where it is used. A citation
to a whole PDF cannot substitute for finding the required hypothesis.

Integrate useful background into the main argument or a linked concept note.
Do not create one compulsory summary per downloaded paper. A small literature
map is useful when it explains which source answers which part of the question.
Downloaded papers retain their own licenses; link them rather than redistributing
third-party full text inside a plugin example.

Record the search boundary when discussing novelty or an apparent absence.
Failing to find a construction does not establish that no construction exists.
If the source is unavailable, mark the claim as awaiting source inspection and
continue only work that does not require treating it as established.
