# Edward Witten ArXiv Corpus, 2011-2026

Retained from the researcher's `witten-style-theory-note` 1.1.0. The counts and
reading markers describe that earlier source study, not a new AITP literature
search. Use the current [writing Skill](../SKILL.md) for authoring instructions.

## Purpose And Scope

This file is the provenance layer for the writing patterns used by the skill.
It is not a claim that every paper below was read line by line, and it is not a
license to imitate sentence-level style.

The census was made from the arXiv API with an exact `Edward Witten` author
match, submission date from 2011-01-01 through 2026-07-11, and descending
submission order. It contains 88 records. The census includes coauthored work
and two outer-solar-system papers that are not evidence for theory-writing
practice. Coauthored prose cannot be attributed to one author with certainty;
the analysis therefore speaks about recurring corpus patterns rather than a
personal voice.

`[C]` marks the 27 papers sampled for closer inspection of introductions,
section dependencies, derivation or proof structure, examples, qualifications,
and conclusions. Close reading was stratified by period and manuscript type.

## Use Boundaries

- The census supports claims about coverage, not claims that all 88 papers were
  close-read.
- The close-read sample supports architecture and proof-pattern extraction,
  not sentence-level imitation.
- Jointly authored papers are evidence for published manuscript practice, not
  uniquely attributable personal habits.
- A pattern inferred from one paper must be labeled genre-specific until it is
  observed in multiple papers of the same type.
- Re-run the census when the date cutoff matters; the 2026 list can change.
