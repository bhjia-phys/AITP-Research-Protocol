# Paragraph

Two normalized state vectors that differ only by a constant phase describe the
same pure state. If |phi> = exp(i theta)|psi>, with real theta, then for every
Hermitian observable A, <phi|A|phi> = <psi|A|psi>: the two phase factors cancel.
Thus expectation values cannot distinguish these vectors. This argument concerns
a common phase multiplying the whole vector; changing the relative phase between
components can change expectation values.
