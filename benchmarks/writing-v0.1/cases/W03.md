# Passage

For smooth 2 pi-periodic functions, define P0 f = (1/(2 pi)) integral_0^(2 pi) f(x) dx.
The derivative D=d/dx has kernel the constants. On mean-zero Fourier series let
Dplus f = sum_(n != 0) f_n exp(i n x)/(i n). Then D Dplus f = f-P0 f.
Thus D u = f has a periodic solution iff P0 f=0, and all such solutions are
u=Dplus f+c. This statement is restricted to smooth periodic functions.
