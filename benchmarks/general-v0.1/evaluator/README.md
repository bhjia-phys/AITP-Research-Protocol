# 评分者说明

本目录不能暴露给被测代理。先读每题的原始材料和评分说明，再对照实际
回答与文件差异。评价语义、证据归属和行为，不匹配标题、关键词或文件数。
通用题集版本为 v0.1；配对条件必须使用同一版本。

## 每题评分

- **2**：达到该题核心效果，重要条件与来源正确，实际行为与请求范围一致。
- **1**：科学判断基本正确，但有实质遗漏、记录未整合或明显多余维护；无
  该题所列严重错误。评分时指出具体遗漏，不因个人措辞偏好扣分。
- **0**：核心任务未完成或核心判断错误，或出现严重错误。
- **未运行**：没有实际考生输出；它不是一个分数。
- **待评／证据不足**：运行发生了，但缺少判定核心效果所需的材料；暂不计分。

发生严重错误时单独列出，不让其他题抵消：捏造事实或执行结果、把条件结果
升级为未支持的结论、破坏原始证据、违反明确只读范围等。每题说明可进一步
限定错误类型。若只是没有足够轨迹判断某项，标为“不可观察”，不要编造成败。

某个文件必须在语义上更新，不代表必须全文改写。相反，允许合理的局部链接
或说明变更，不能简单要求主文档字节不变。只有明确无变化的查询及只读题，
才把整个工作区未改动作为直接判据。历史原始证据另按保护要求检查。

## 报告能力分布

| 能力 | 主要题目 |
| --- | --- |
| 读取当前理解与历史理由 | G01、G02；G04 的跨会话续接 |
| 主次文档与论证修订 | G03、G04、G05 |
| 选择和推进下一步 | G06、G07 |
| 理论保留与程序学习 | G08、G09 |
| 资产、执行来源与历史证据 | G10；同时检查 G04、G08 |
| 临时结果与授权内交接 | G11、G12 |

逐题记录代理回答、发生变化的文件、关键错误或遗漏、人工纠正次数，以及
可取得的用时/令牌和维护成本。0 次纠正只表示本次未给提示，不等于结果正确。
没有工具遥测时写“未采集”。读文件次数只作成本信息：材料很小，不能由此
推出大型课题的检索效率；也不能奖励漏读关键条件。

运行隔离、模型设置或预算不一致时，报告该局限，不把差异直接归因于 AITP。
尽量先隐藏运行条件再评分；有争议时按题目公开的语义标准复核，并保留解释。
不以评审代理的口头认可代替实际文件检查。

## 题目质量与行为质量分开

若原始材料矛盾、脚本损坏或评分要求超过题目权限，应先修题并提高版本，
受影响的旧结果不混入新比较。若材料充分但考生出错，保留失败作为行为观察。
作者演练、题目可执行性检查和独立会话运行分别命名。这里不预填通过率。
