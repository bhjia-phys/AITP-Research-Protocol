# Candidate integral study

This workspace is a synthetic mathematical study. Its target and agreements
are described in [research.md](research.md).

- [Model and error bound](notes/model-and-error.md) defines the numerical quantity.
- [Quadrature script](code/quadrature.py) prints a CSV row for a chosen grid:
  `python3 code/quadrature.py 8`.
- [Existing grid checks](results/grid_checks.csv) records the completed calculations.

Scripts live in `code/`, numerical outputs in `results/`, and explanations in
`notes/`. The files represent a static starting point, not a live external job.
