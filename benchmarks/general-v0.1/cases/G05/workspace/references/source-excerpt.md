# Supplied source excerpt: normalized weighted averages

This is invented source material for a synthetic exercise, not a quotation from
a real publication. It may be treated as a supplied mathematical starting point.

For real x1 and x2, w1 >= 0, w2 >= 0 and w1+w2 = 1, the quantity
q = w1*x1+w2*x2 lies between min(x1,x2) and max(x1,x2).

Proof: writing w2 = 1-w1 gives q = x2+w1*(x1-x2), where 0 <= w1 <= 1.

This excerpt makes no assertion about a measured instrument response, and does
not discuss exchanging channels while keeping their weights fixed.
